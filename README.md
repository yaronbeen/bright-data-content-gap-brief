# Content Gap Brief

Find out whether your site already answers a question before commissioning another article.

Your agent uses [Bright Data](https://brightdata.com) to find relevant competing pages and collect article bodies, then the bundled skill turns that evidence into an editorial decision.

## What You Get

- One writer assignment with an outline, checks and an example to develop.
- A cited "Do Not Commission" decision when your page already answers the question.
- A needs-review handoff when the evidence isn't enough to decide.

## Give This To Your Agent

```text
For [question and reader task], compare [my article URL] with up to three
relevant competing articles. Use one search query and one result page
through my configured Bright Data search tool, then collect the selected
article bodies with Bright Data Web Unlocker. Follow
gap-to-writer-assignment using [required points and example context].
Return one cited assignment, a supported Do Not Commission decision,
or a needs-review handoff. Keep source quotes, dates and unknowns.
If tools are unavailable, ask for Bright Data exports.
```

Skill: [gap-to-writer-assignment](skills/gap-to-writer-assignment/SKILL.md).

In the [checked example (invented data)](docs/skills/gap-to-writer-assignment-example.md), the assignment covers failed-import checks while leaving out a CSV question the owned page already answers.
